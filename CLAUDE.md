# PROYECTO: ARCHIPELAGO

Toda la documentación de este proyecto — visión a largo plazo, los 73 principios, el roadmap operativo con Definition of Done por fase, y las reglas de proceso para trabajar con Claude Code — vive en la bóveda de Obsidian de este repo, en [`vault/`](vault/00%20Index.md). Este archivo ya no duplica ese contenido: es solo el punto de entrada obligatorio.

**Antes de proponer o tocar nada en este proyecto:**

1. Lee [`vault/00 Index.md`](vault/00%20Index.md).
2. Desde ahí, lee `Roadmap/Estado del proyecto.md` para saber en qué fase estamos y qué falta.
3. Lee las notas de la carpeta `Claude/` (rol, reglas de ingeniería, convenciones de trabajo) — rigen cómo debes comportarte en este repo.

Si algo de la visión (carpetas Vision/Jugador y vehículos/Economía/Mundo/Tecnología/Principios) choca con el roadmap operativo, gana el roadmap hasta que una fase concreta diga lo contrario.
