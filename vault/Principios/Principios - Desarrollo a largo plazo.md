# Principios — Desarrollo a largo plazo (66-72)

66. Nunca construir arquitectura temporal que se espera vuelva permanente.
67. Todo sistema debe ser reemplazable.
68. Toda dependencia debe justificar su existencia.
69. El refactor se espera.
70. La documentación es parte del código.
71. El profiling es obligatorio antes de optimizar.
72. La deuda técnica se rastrea, no se ignora.
