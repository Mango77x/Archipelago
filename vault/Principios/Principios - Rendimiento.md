# Principios — Rendimiento (33-39)

33-34. CPU y memoria son recursos — se gastan solo si se justifica.
35. Todo sistema debe ser escalable.
36. Todo algoritmo caro debe tener una razón de existir.
37-38. La localidad de datos y los cache misses importan.
39. El multithreading se considera desde el principio (del diseño, no de la implementación día 1 — ver [[Roadmap tecnológico]]).
